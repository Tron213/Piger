# Piger
Миленькие маленькие поросятки, помогают отслеживать состояние серверов, а также бдят и записывают журнал логов 

# Возможности 
Мониторинг ip, история пингов, график аптайма, много много свинок

# Технологический стек
FastAPI, PostgreSQL, SQLAlchemy, Docker, chart.js

# Архитектура
Ping worker -> PostgreSQL -> FastAPI -> SQL

# Структура проекта
1. App - основная папка бекенд приложения
2. Worker - качка пингов
3. Docker - настройка докера 

# Требования 
все зависимости указаны в requrements.txt
